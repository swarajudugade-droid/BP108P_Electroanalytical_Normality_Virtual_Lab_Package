PharmaCalc – BP108P Electro-analytical Normality Virtual Laboratory

Files:
- BP108P_Electroanalytical_Normality_Virtual_Lab.html

How to use:
1. Extract the ZIP package to a folder.
2. Double-click the HTML file, or right-click and open with Chrome or Microsoft Edge.
3. No internet connection or installation is required.
4. Use the tabs for the three simulations and the post-test/record tools.

Experiments:
1. Conductometric titration of strong acid against strong base.
2. Conductometric titration of a strong-acid/weak-acid mixture against strong base.
3. Potentiometric titration of strong acid against strong base.

Features:
- Interactive simulated curves and observation tables
- Normality calculations and endpoint inputs
- CSV observation export
- Quiz and practical record export (Word-compatible .doc, TXT, print/save as PDF)
- Educational precautions and creator credits

Important:
This is a teaching simulator. Curves and readings are simulated, not measured experimental data. Confirm the endpoint interpretation, sample/titrant concentrations, electrode calibration, temperature control and calculations with the prescribed practical manual and instructor before using in a real laboratory.
